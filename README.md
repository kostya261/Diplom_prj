# TaskTracker — Система управления задачами, инструментом и складом

Дипломный проект. Представляет собой серверное приложение (REST API) и веб-интерфейс для управления сотрудниками, 
задачами, складом инструментов и материалов.

## Возможности

*   **Управление сотрудниками**: создание, редактирование, назначение ролей (админ, менеджер, сотрудник), отделы.
   **Управление задачами**: создание, назначение ответственных и соисполнителей, отслеживание статуса 
      (`new`, `in_progress`, `done`), приоритеты, комментарии, история изменений.
*   **Специальные эндпоинты (по ТЗ)**:
    *   Загруженность сотрудников (`/api/tasks/employee_load/`)
    *   Поиск важных задач и назначение исполнителя (`/api/tasks/important_tasks/`)
*   **Учёт инструмента**: справочники (категории, производители, места хранения), 
учёт выдачи и возврата инструмента сотрудникам.
*   **Складской учёт**: товары, остатки, приход/расход материалов, связь расхода с задачами.
*   **Печатные формы (PDF)**: генерация документов 
(остатки, инвентаризация, карточка инструмента, акт выдачи, наряд-заказ).
*   **Полноценный веб-интерфейс** (Bootstrap 5) для всех операций без использования админки Django.

## Технологии

*   **Backend**: Python 3.13, Django 5.2, Django REST Framework
*   **База данных**: PostgreSQL
*   **Авторизация**: JWT (djangorestframework-simplejwt)
*   **Документация API**: Swagger (drf-yasg)
*   **Контейнеризация**: Docker, Docker Compose
*   **Фронтенд**: Bootstrap 5, HTML-шаблоны Django
*   **PDF**: pdfkit + wkhtmltopdf
*   **Тестирование**: unittest, coverage (покрытие >75%)

## Установка и запуск (локально)

### Предварительные требования
*   Python 3.13+
*   PostgreSQL (или можно оставить SQLite для теста, изменив настройки в `.env`)
*   Утилита `wkhtmltopdf` (для генерации PDF).
[Скачать](https://github.com/wkhtmltopdf/packaging/releases/download/0.12.6-1/wkhtmltox-0.12.6-1.msvc2015-win64.exe) и установить, добавив путь в `PATH` или указав его в переменной окружения `WKHTMLTOPDF_PATH`.

### Шаги по установке

1.  **Клонировать репозиторий**
    ```bash
    git clone <url-твоего-репозитория>
    cd TaskTracker
    
2. **Создать и активировать виртуальное окружение (через poetry)**


    poetry install
    poetry shell

3. **Настройка переменных окружения**

Создайте файл .env в корне проекта на основе .env.example:

    env
    SECRET_KEY=your-secret-key
    DB_NAME=tasktracker_db
    DB_USER=postgres
    DB_PASSWORD=your_password
    DB_HOST=localhost
    DB_PORT=5432
    WKHTMLTOPDF_PATH="C:\Program Files\wkhtmltopdf\bin\wkhtmltopdf.exe" # Для Windows

4. **Применить миграции**


    python manage.py migrate

5. **Создать суперпользователя (для доступа в админку)**


    python manage.py createsuperuser

6. **Запустить сервер разработки**


    python manage.py runserver

7. **Открыть в браузере**

Веб-интерфейс: http://127.0.0.1:8000/

Swagger документация: http://127.0.0.1:8000/swagger/

Админка Django: http://127.0.0.1:8000/admin/


## Запуск через Docker

Это самый простой способ запустить проект в изолированном окружении.

1. Убедитесь, что установлены Docker и Docker Compose.
2. Склонируйте репозиторий (см. выше).
3. Запустите контейнеры


    docker-compose up --build

4. Проект будет доступен по адресу http://127.0.0.1:8000/.

Структура проекта

    config/ — настройки проекта Django (главный urls.py, settings.py).
    core/ — общие утилиты (например, utils.py для генерации PDF).
    users/ — приложение для управления сотрудниками.
    departments/ — приложение для справочника отделов.
    tasks/ — приложение для управления задачами.
    inventory/ — приложение для учёта инструмента.
    warehouse/ — приложение для складского учёта.
    templates/ — общие HTML-шаблоны.
    static/ — статические файлы (CSS, шрифты).
    media/ — загружаемые пользователями файлы (фото товаров/инструментов).
    requirements/ или pyproject.toml — зависимости проекта.

### API Документация
Интерактивная документация доступна по адресу /swagger/ после запуска сервера. Там можно посмотреть все доступные эндпоинты и даже протестировать их.

### Тестирование
Проект покрыт тестами (модели, API, права доступа). Для запуска тестов выполните:


    coverage run --source='.' manage.py test
    coverage report

### Печатные формы
Генерация PDF доступна из веб-интерфейса. Для корректной работы требуется установленный weasyprint. Примеры отчётов:

    Остатки на складе: /warehouse/reports/stock-balance/
    Инвентаризация: /warehouse/reports/inventory/
    Карточка инструмента: /inventory/<id>/report/
    Акт выдачи: /inventory/issues/<id>/report/
    Наряд-заказ: /tasks/<id>/order/
